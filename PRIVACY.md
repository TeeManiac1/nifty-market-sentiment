# Privacy Policy

**Effective date:** July 2026

Nifty Market Sentiment Research is an independent research and educational project focused on quantitative finance, natural language processing, and public market-commentary analysis.

## 1. Overview

This project uses publicly available YouTube metadata and, where available, publicly accessible transcript text for internal research and analysis.

The purpose of the project is to study whether stock-market commentary contains useful signals about future market behaviour, and to build internal research datasets for quantitative analysis.

This project is not a public video platform, is not a downloader, and is not affiliated with YouTube or Google.

## 2. Information this project uses

This project may collect and process the following types of information from public YouTube content:

- public video titles
- public video descriptions
- public channel names
- public publication dates
- public video IDs and channel IDs
- public playlist and metadata fields available through the YouTube Data API
- publicly accessible transcript text, where available
- internally generated research fields derived from that public content, such as stock mentions, sentiment labels, and structured research features

## 3. Information this project does not collect

This project does **not** collect or store:

- YouTube user passwords
- private account information
- non-public user data
- private messages
- user login credentials
- personal financial account information
- private viewer behaviour data
- comments or private interactions unless separately and explicitly added in the future

This project is not intended to identify or profile individual YouTube users.

## 4. How the information is used

The information processed by this project is used only for internal research, experimentation, and educational purposes, including:

- building structured research datasets
- transcript processing and text analysis
- natural language processing experiments
- stock-mention extraction
- market-signal research
- quantitative finance backtesting and evaluation
- internal model development and project documentation

## 5. No redistribution of YouTube content

This project does **not**:

- republish YouTube videos
- provide public access to stored YouTube videos
- offer a YouTube video downloading service
- redistribute transcript content as a standalone public product
- create a substitute viewing experience for YouTube

Any YouTube-derived data used in this project is used only as part of internal research workflows.

## 6. Data sharing

This project does not sell personal data and does not share collected research data with third parties for advertising purposes.

Any outputs produced by this project are intended for internal research, educational demonstration, and portfolio purposes. If public summaries or results are later published, they will be presented in aggregated or research-oriented form rather than as a republication of YouTube content.

## 7. Data retention

Public metadata and transcript-derived research data may be stored for as long as needed for research, testing, reproducibility, debugging, and model evaluation.

Stored data may include cleaned or transformed versions of public metadata and transcript text used in internal pipelines.

## 8. Security

Reasonable efforts are made to store project data securely in local development environments, private project files, and research datasets.

However, this is an independent research project and no guarantee of absolute security can be made.

## 9. Children’s privacy

This project is not directed at children and is not designed to collect personal information from children.

## 10. Changes to this policy

This Privacy Policy may be updated from time to time as the project evolves. Any updated version will be posted in this repository.
